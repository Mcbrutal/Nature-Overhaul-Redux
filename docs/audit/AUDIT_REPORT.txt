Method and reason:
This was a class-by-class audit of every object, not a vegetation-only pass. Every one
of the 201 used BuilderItems classes was resolved in the supplied converted configs and
compared by model path and base behavior with current DayZ definitions.

Every tree, bush, grass, ivy and cut-tree placement now uses the exact native P3D path
from its BuilderItems definition. TreeHard, TreeSoft, BushHard and BushSoft names were
removed because they are CfgNonAIVehicles terrain definitions and DayZ Editor rejects
them as world objects. Static props with an exact current DayZ class using the identical
model and HouseNoDestruct base were changed to that native class.
Positions, rotations, scales, array ordering and every other field were preserved exactly.

Safety decisions:
bldr_PortableGasLamp was retained because the same-model vanilla PortableGasLamp is an
Inventory_Base item; substituting it would change scenery into a pickup item. Nine other
BuilderItems classes were retained because they are standalone proxy/legacy models with
no exact native standalone class. Approximate visual substitutions were not made.

Book and inventory-item check:
No book, paper, magazine or newspaper SpawnObject call exists in the original scripts
or in the 8,297 converted placements. The original source confirms no book was omitted.
The sole inventory-model match is bldr_PortableGasLamp, which was intentionally kept as
a static wrapper. Native inventory classes were not introduced anywhere in this revision.

Vegetation compatibility:
All 1,416 former TreeHard/TreeSoft/BushHard/BushSoft output names were replaced with
their exact model paths after DayZ Editor reported all 105 such objects in
Balota_circel.json as invalid. This same correction was applied across every location.
All 36 Land_WindPowerPlant_Grey placements loaded without error in DayZ Editor and were
therefore retained unchanged.
